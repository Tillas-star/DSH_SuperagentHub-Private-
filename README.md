# DSH SuperAgent

DSH SuperAgent 是一个自动化开发助手。它关联本仓库，可以按需求在独立分支上修改代码，并提交 Pull Request 供人工审阅。

## 仓库信息

| 项目 | 内容 |
| --- | --- |
| 仓库名 | `Tillas-star/DSH_SuperagentHub-Private-` |
| 默认分支 | `main` |
| 仓库地址 | <https://github.com/Tillas-star/DSH_SuperagentHub-Private-> |

## 目录结构

```text
.
└── README.md   仓库介绍
```

## 使用方式

1. 在飞书群聊中 @DSH_SuperAgent，或在 GitHub 仓库的 Issue 中提出需求。
2. DSH SuperAgent 在独立分支上完成修改，并创建 Pull Request。
3. 维护者审阅并合并 Pull Request。
