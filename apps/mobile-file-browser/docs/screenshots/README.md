# 界面截图

这些截图由 Playwright 在 Chromium 中以 390×844 手机视口（2x）拍摄，使用 `.e2e/` 下由 sharp 生成的纯色示例图片，不包含任何真实照片、个人目录或内网地址。

- `login.png`：外网/密码登录页（本地模式下设置了访问密码）。
- `browse.png`：根目录，文件夹在前、图片网格、其他文件置灰。
- `folder.png`：子目录与面包屑。
- `viewer.png`：全屏图片查看、序号与上一张/下一张。
- `roots.png`：切换根目录面板。

“之前”的界面不存在：该功能在本仓库中从零新增，没有旧版页面可作基线截图。
